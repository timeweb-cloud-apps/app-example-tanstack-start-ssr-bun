# tanstack-start on bun (SSR)

Пример tanstack-start на bun для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `bun` |
| Фреймворк в API | `tanstack-start` |
| Тип приложения | `backend` |
| Команда сборки | `bun run build` |
| Команда запуска | `bun run start` |

## Локальный запуск

```bash
bun install
bun run build
bun run start
```
